# 核心封装与请求头

0.5.1 将网络连通性与 state 资格分开：收到可解析状态头但不符合规则的节点仍可普通转发，不再因此成为失败代理。兼容转发可以没有合格 state；严格拒绝通过宿主已有的终止性保护错误返回，避免错误处罚账号。首次同步采集默认整轮 20 秒，而非最多六次超时相加。

逐节点验证使用已有运行会话做真实短请求，结果分别记录是否收到头、封装是否可解析、实际长度/块数与规则是否相符。后台任务分轮、遵守冷却和上游暂停、可取消。关闭注入时也能明确发起验证；验证本身不替换正在使用的 state，令牌只在单次检查内存中存在。

0.5.0 的生产入口 `cmd/plugin/main.go → transport.CoreRuntime → upstream/gateway.Engine` 直接使用上游提交 `b18fabf9ad8e9d7af7d9d0306b623ba6091a39d6` 的网关、状态机、账号规则、压缩协议与节点生命周期。原始文件哈希和适配差异记录在 `provenance/source-manifest.json`。

## 请求头行为

| 场景 | 行为 |
| --- | --- |
| 短请求采集 | 仅保留 Authorization、ChatGPT-Account-Id、User-Agent、Version、Originator、OpenAI-Beta；设置 JSON/SSE 类型；不复制旧 state、session/conversation、Cookie 或请求压缩声明 |
| 正式普通生成 | 保护开启且取得有效 state 时设置 X-Codex-Turn-State；其余宿主出站头继续按上游处理；去除 Cookie、Proxy-Authorization 与逐跳头 |
| 关闭注入或普通兜底 | 不伪造已注入；保留客户端经宿主处理后的原 state 头，正式请求只发一次 |
| V1/V2 远程压缩 | 不触发普通采集，不按普通生成覆盖原 state；复用上游压缩桥接与有界响应处理 |
| 响应 | 返回 X-Codex-Turn-State，去除 Set-Cookie；不把任意响应直接发布为主用 state；不合格正式响应拦正文并尝试提升备用给下一请求 |

采集 body 保留上游的 `parallel_tool_calls:true` 和 `include:["reasoning.encrypted_content"]`。不降低请求中的模型或推理档位。

## 运行状态和持久化

状态令牌和鉴权只驻留内存。按宿主账号分配的网关内部继续按 `Authorization + ChatGPT-Account-Id + model` 隔离，不因同账号换凭据复用旧 state。对同凭据的上游拒绝在更换模型、配置或订阅路由后仍然保留；原始凭据变更使用新的隔离空间。

新配置默认 `on_demand`：拿到后固定使用，直到无效或过期。`standby` 模式在运行进程内为近期真实请求激活的会话准备备用；停用进程不会虚构后台采集。没有真实请求提供的鉴权时，页面显示“暂无运行会话”。手动采集同样受冷却和上游暂停限制。

节点池的 available/used/failed/disabled 状态持久化在：

```text
<宿主插件目录>/installed/local.sub2api.ccodex-sleep-state/.state/routepool.json
```

路径从已安装二进制的严格目录结构推导，不使用工作目录、系统临时目录或用户 Home 兜底；验证链接路径、限制文件体积，使用跨进程锁与原子替换。仅保存匿名节点 ID、状态、次数和安全原因码。它适配当前 0.2.7 安装布局，并非 SDK 数据目录契约。文件不可读写或损坏会明确报错，不静默重置。升级保留记录，卸载后的记录也可能保留；界面可回收或停用节点。

每次节点认领与人工操作带有修订标识。请求完成只更新仍属于该次认领的记录，避免在途请求覆盖用户刚做的停用或回收。切换注入和主备策略原位更新，不清空仍可用的主用/备用值；退役的健康凭据记录会释放，已拒绝或仍在冷却的凭据不会因此重获尝试机会。

## 宿主边界

插件处理宿主准备好的 OpenAI OAuth 请求。宿主账号选择、鉴权、用量计费和通道路由保持宿主职责；上游独立程序的 Codex 配置接管、本地面板监听、CCS 和 API Key/relay 通道不在此保护传输接口中运行。

宿主普通 Responses 路径已经过滤的原始客户端 OpenAI-Beta 值不能被插件恢复。插件保留实际收到的头，不编造原值；X-Codex-Turn-State 则在宿主请求/响应路径中显式支持。宿主也不向插件提供权威套餐字段：自动账号规则采用上游令牌提示逻辑，工作区不匹配或提示不明时采用个人规则，可手动选 Team。长度只是一条经验规则。

插件额外适配：跨网关代际共享拒绝状态和采集串行槽；尊重旧的采集关闭开关、模型范围和精确字节限制；通过 gRPC 的 RequestSent 标识阻止宿主将已发送后产生的本地错误当作可安全重放。配置变更先停止旧后台采集，活动请求保留自己的不可变出口快照。

节点连通性、state 合格性和真实模型响应是不同结果。验证中的合成令牌只用于本地协议回归，不宣称真实账号已取得目标 state 或模型质量提升。
