# 0.5.1 验证范围

本文件说明验收方法。最终包结果与 SHA-256 记录在仓库 `docs/2026-09-19_ccodex-sleep-state-0.5.1-proxy-repair-report.md`；不在包内嵌入包自身的哈希。

- 故障复现：真实 0.5.0 签名包在错形状兼容、严格本地拒绝和配置新模型三项失败，不将“能安装”视为成功转发证据。
- 签名包成功转发：真实宿主 RoundTripOpenAIOAuth → 插件子进程 → CONNECT 代理 → 本地 TLS/SSE 上游；逐条确认请求来自代理连接，验证采集与正式正文分离、正确注入及正式请求成功。
- 逐节点资格：实际 TLS/CONNECT 多节点响应，覆盖缺头、非法头、块数不符、合格、未完整结束与网络失败；取消/冷却/上游暂停、关闭注入手动验证、实例退休清理；不改 active/standby。
- 兼容性：资格失败不会让正常代理不可用；严格本地拒绝不触发宿主账号轮换；旧版误分类只作针对性恢复；模型白名单与总时间预算生效。

- 上游核心：保留上游 gateway、turnstate、settings、routepool、fsutil 原始回归套件；记录固定提交 b18fabf。
- 请求头真实网络：本地 HTTPS 上游核对六个采集身份头、不带对话链，正式生成注入 X-Codex-Turn-State，响应头进入宿主 RPC 帧。
- 核心适配：凭据/工作区/模型隔离、个人/Team、held/standby、限次/冷却、配置变更保留 401/403/429、gzip/zstd、V1/V2 compact、不合格 state 拦正文且 RequestSent=true、不重放、截断流无成功 End。
- 生命周期池：独立进程并发认领、更新不丢失、跨进程回收可见、损坏/符号链接拒绝、锁超时和 Windows/Linux 路径/权限。

- 单元与契约：配置继承、一次性节点命令、报告恢复不重放、节点选择、连接池保留、刷新和 state 行为。
- 本地真实网络：HTTP CONNECT、带特殊字符密码 HTTP、SOCKS5/SOCKS5H、HTTPS 上游和代理认证失败；确认代理凭据不泄露到上游。
- 诊断：节点名称、稳定 ID、HTTP 状态、延迟、407/超时/TLS/403/429 分类与超时未完成状态。
- 浏览器：获取节点、逐节点测试、选择固定出口、保存重开、无效订阅、窄屏布局、加载失败不覆盖和来源过滤条件保留；核心开关/策略/状态、冷却禁用、手动采集和节点回收/停用，不覆盖草稿。
- 真实宿主：签名包安装及 UI 静态资源、实际 PluginManager 配置保存与读取、停用状态临时插件进程，不伪造 plugin.status 成功响应。
- 包：Ed25519 签名、资源哈希、三平台二进制格式、Windows 和 Linux 插件握手；arm64 通过 QEMU 验证，不等同于原生硬件负载测试。

连接测试不发送 OAuth 凭据、不调用付费模型。单次测试结果反映测试时刻的网络状态，不能保证服务商节点一直可用。未进行生产账号推理或长时间负载验证。
