# Sub2API Cost Console v0.2.39

## 主要更新

- 插件管理支持 v2 通用扩展：请求预处理、OpenAI OAuth 保护传输、Host API、按账号/用户/分组设置路由与灰度。
- 支持插件安装、启用、停用、卸载，以及升级后的限时版本回滚。
- 修复桌面端插件配置窗口空白；加载失败会给出提示和重试入口。
- 插件列表改为紧凑布局，支持搜索、状态筛选和独立展开详情，方便管理多个插件。
- 保留成本账本、经济采样、Docker 恢复、受管内核双槽回滚及 Windows 原生一键启动。

## 当前兼容内核

- 上游 Sub2API：`v0.2.5`
- 上游提交：`86f93c28ee34cc74b629dafb748bd5ac5ca8c5ea`
- 本地扩展：`v1.2.0`
- 成本算法：`v1.6.1`
- 必需能力：`account_cost_loss_ledger.v1`、`account_economics_sampling.v1`、`plugin_extensions.v2`、`openai.oauth.protection_transport.v1`

## 技术变更

- 增加 v2 SDK、能力清单和双向流保护传输，复用宿主账号选择及用量计费；v1 传输接口继续兼容。
- 插件配置使用比较更新，拒绝过期覆盖；持久化失败恢复已保存快照，避免重复执行配置动作。
- Host API 提供受限配置读取、事件、日志、指标与有期限的秘密授权；权限按能力检查。
- UI 资源以真实后端地址加载；受限 iframe 校验窗口、来源和 Bridge Token，等待 ready 消息并处理超时和迟到响应。
- 可选容器隔离供无网络 v2 扩展使用；OpenAI OAuth 保护传输要求 process 模式，一个请求仅选中首个匹配的保护传输。
- 补齐插件相关资源关闭、测试类型断言和静态检查问题；Unix socket 桥接只允许容器内 `/rpc/` 路径。

## 升级行为

- 本包为正式桌面程序，继续使用正式应用标识、原有数据目录和升级通道；无需安装独立 Plugin Preview。
- 扩展版本升至 1.2.0，并声明插件必需能力，升级时会识别缺少这些能力的旧受管内核。
- 数据库增加插件版本历史、细粒度路由和秘密授权表/字段（迁移 239–241），不批量修改账号和历史费用数据。
- 安装器仅包含主程序与宿主 SDK，不包含本机开发的独立插件或发布者私钥。第三方插件仍按管理员配置的发布者公钥验签；未加入通用的发布者授权界面。
- 插件安装与启用由管理员选择，升级主程序不会自动安装或启用本机私有插件。

## 验证结果

- 已有回归覆盖插件签名、能力权限、请求路由、真实子进程、配置快照与回滚、流式生命周期及数据库比较更新。
- 配置页面已通过真实包资源与桌面来源的浏览器验证；多插件搜索、折叠、保存、加载超时及重试有回归覆盖。
- 正式发布工作流重新执行前端全量、静态检查、Rust 启动/升级契约，并构建带更新签名的 Windows x64 NSIS 安装器。
- 最终 CI、公开下载与安装包签名核验记录见 `docs/2026-09-18_development-desktop-v0.2.39-release-report.md`。

## 回滚说明

- 插件版本回滚保留最近 5 个快照、最长 24 小时；卸载会移除该插件历史。
- 主程序/内核回退不会自动撤销数据库结构迁移。回退至不支持 v2 的版本前，应先停用 v2 插件，并备份数据库和配置。
- 桌面安装包与独立内核是不同更新层，回滚内核不替换桌面前端。
