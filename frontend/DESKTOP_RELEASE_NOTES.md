# Sub2API Cost Console v0.3.0

## 主要更新

- 普通用户可以导入已编译的 `.s2plugin`，首次遇到发布者时在界面确认信任，无需编译插件或手动修改公钥配置。
- 安装前显示插件信息、声明权限和签名指纹；同一发布者后续安装与升级无需重复确认。
- 插件包内置发布者公钥，宿主验证签名及全部文件，再按用户确认保存信任；不会自动放行任意包内公钥。
- 保留插件安装、配置、启停、卸载、灰度、作用域与版本回滚，以及成本管理、Docker 恢复和 Windows 原生一键启动。

## 技术变更

- 新增只读的插件包检查接口，在安装和执行前验证清单、签名、文件哈希、大小及平台兼容性。
- 首次授权绑定本次上传的包 SHA-256 和发布者指纹；换文件或换公钥后旧确认不能复用。
- 发布者公钥与安装/升级记录在同一数据库事务中保存；失败不遗留信任记录，并发同名不同公钥只有一个可成功。
- 内置公钥与已有 `plugins.trusted_publishers` 配置保持优先，包内公钥无法覆盖既有信任；未签名包仍默认拒绝。
- 新增数据库迁移 242 保存发布者信任，支持重启及多实例共享。接口沿用管理员认证与二次验证。
- SDK 打包器自动附带 `signature.json.public_key`，发布页继续提供开发指南、SDK 与公开示例。

## 升级行为

- 使用本正式桌面安装包升级即可；启动时会用扩展 1.3.0 替换缺少新安装能力的旧受管内核。
- 用户需要的是作者已经编译好的 `.s2plugin`，不是 SDK 或源码 ZIP。首次确认后安装默认停用，按插件需要配置并启用。
- 旧签名包如果发布者已经受信任，可继续使用。若首次安装的旧包没有内置公钥，应由作者重新提供新版成品包，接收者不用编译。
- 信任确认无需重启宿主。已有公钥配置继续兼容，正式版不会预置本机私有插件的发布者公钥。
- 本机私有插件源码和安装包不随主程序公开发布。

## 验证结果

- 使用实际成品包复现旧正式版缺少发布者信任的错误，确认原包的二进制、签名和文件内容有效。
- 回归覆盖未确认拒绝、取消、摘要不匹配、文件篡改、公钥冲突、内置公钥保护和既有公钥兼容。
- 真实 PostgreSQL 测试覆盖安装失败回滚信任、升级失败回滚信任及并发同名公钥冲突。
- 真实浏览器与隔离宿主/数据库完成首次发布者确认、成品安装、启用、配置、无需重复确认的升级、回滚和停用；未使用生产账号或数据库。
- 最终构建、CI、签名与公开下载验收见 `docs/2026-09-18_development-desktop-v0.3.0-release-report.md`。

## 回滚说明

- 新增的发布者信任表不会因回退旧版本而自动移除，回退前请备份数据库与配置。
- 旧主程序不会读取界面保存的发布者信任；使用新信任流程安装的插件在旧版上可能无法恢复，需先停用相关插件。
- 插件权限、协议与运行策略没有因首次信任被放宽，停用和卸载仍通过原有管理流程处理。
