# Sub2API Cost Console v0.2.34

## 主要更新

### 修复登录失效后的空白仪表盘与重复请求

- 收到无法恢复的 401 时，同步清除客户端内存和本地存储中的登录状态，再返回登录页，避免被旧的管理员状态弹回仪表盘。
- 多个业务请求同时返回 401 时，登录页跳转与会话失效提示只触发一次；正确识别桌面的 Hash 路由及登录页查询参数。
- 令牌刷新后再次收到 401，也会结束失效会话并要求重新登录。
- 自动刷新令牌被拒绝时清除会话并停止刷新计时器。
- 网络中断、超时、限流或刷新服务 5xx 等临时故障保留现有凭据，等待恢复后重试。
- 旧用户请求、刷新成功后换号及迟到的用户信息不能注销、覆盖或恢复另一份登录会话。
- 登录表单的凭据错误保持在登录流程中，不额外触发“会话失效”跳转。

### 保留启动恢复与 Windows 原生一键启动

- 保留 Docker 和数据容器恢复、真正的内核停止等待与重试、单实例和异常退出清理。
- 保留 ChatGPT Desktop、Codex CLI、Claude Code、Cursor Agent、OpenCode 和 Grok CLI 的原生启动能力。
- 保留成本真实性面板、成本损失账本和经济采样。

## 技术变更

- 使用同步的会话失效通知连接 HTTP 拦截器与 Pinia 状态，避免互相导入导致的依赖循环。
- HTTP 请求保留用户身份，重试前后检查当前会话，拒绝跨用户重放。
- 用户信息与自动令牌刷新使用会话代次，阻止失效后的异步回写。
- 回归测试连接实际 HTTP 拦截器、Pinia 和生产路由守卫，不再仅验证 localStorage 被删除。

## 升级行为

- 更新桌面安装包至 `v0.2.34`；只更新独立内核不能修复旧桌面中的登录状态问题。
- 若旧凭据已被服务器拒绝，更新后会正常进入登录页，需要重新登录。
- 本次不新增数据库迁移，不修改账户余额、计费算法或服务连接配置。

## 验证结果

- 修复前复现“存储凭据已删除、内存仍已登录、登录页又被送回仪表盘”的失败场景。
- 新增 15 项回归，覆盖实际路由、并发 401、刷新重放、换号、迟到响应、临时刷新故障和自动刷新计时器。
- 发布门禁包含前端全量测试、ESLint、生产构建和 Rust 桌面生命周期测试。
- 安装包由 GitHub Actions 构建并签名，发布后核对 SHA-256、更新签名和公开自动更新入口，最终记录见发布报告。

## 回滚说明

- 本版仅修复客户端会话处理；回退旧桌面会重新暴露登录失效后的跳转问题。
- 保留既有内核双槽验证与回滚机制；数据库迁移不会随二进制回滚自动撤销。
