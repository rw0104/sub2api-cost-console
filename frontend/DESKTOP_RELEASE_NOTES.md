# Sub2API Cost Console v0.2.28

## 主要更新

### 成本数据真实性与面板精简

- 刷新或单个来源失败时保留最近一次成功快照，并明确显示旧数据/不可用状态；不会把暂时失败伪装成 0 或让成本数据自动消失。
- 统一区分用户 API 计费产出、标准 API 成本、上游账号成本、采购投入和封禁损失；缺少账号成本快照时的标准价回退会明确标为估算。
- 总览默认只保留一张财务事实趋势图；请求质量、账号健康、TTFT、Token、缓存、模型贡献和路由宽表改为按需诊断，减少重复数据和无效统计。
- 模型核对面板同时展示请求模型、实际发往上游模型和响应声明模型；目录声明、真实推理、真实流量、不一致与未观测状态分开计算。

### 兼容内核升级

- 兼容内核从上游 `v0.1.182` 升级到 `v0.1.183`，保留 OAuth、API Key、HTTP 和 WebSocket 的 OpenAI Responses 兼容处理。
- 修复 OpenAI OAuth 5 小时/7 天配额耗尽识别、`session-id` 粘性会话和模型容量溢出时的账号切换策略。
- 修复 Kimi 并发限制 403 的临时冷却与故障转移、OpenAI custom tool/tool search 的项目 ID 前缀恢复，以及 Antigravity 兼容模式 token 上限。
- 修复邮箱换绑别名并发占用检测和渠道监控 V2 Composite 聚合条件，提升账号状态判断准确性。
- 保留成本损失账本、经济采样、精确时间窗口和 Windows 原生客户端启动能力。

### Windows 原生一键启动

本版本在 Release 首屏正式说明 Windows 原生一键启动能力。该功能实际首次随官方 `v0.2.23` 发布；此前名称含 `0.2.22` 的文件只是本地未签名开发构建，不是 `v0.2.22` 官方 Release。

- 分别探测和启动 **ChatGPT Desktop** 与 **Codex CLI**，两者是独立程序，不再混为同一个 Codex 客户端。
- 支持 **Claude Code、Cursor Agent、OpenCode、Grok CLI**。
- 工作目录可浏览选择，成功选择后会显示并保存在本机；客户端路径可重新扫描，也会复用上次有效结果。
- CLI 客户端在独立终端中启动；优先使用 PowerShell 7，未安装时自动回退系统自带的 Windows PowerShell 5.1。
- Base URL、API Key 和客户端所需配置只注入新进程。不会接管 `~/.codex`、`~/.claude` 等账号文件，不做自动切号，也不管理多实例。
- ChatGPT Desktop 只负责启动官方 Windows 应用，不向其强行注入 CLI API 配置。

### 成本中心口径

- “当天”按用户设备的日历日展示并在本地跨日后归零；界面不再暴露内部时区名称。最近 1 小时、6 小时等仍是精确滚动窗口。
- 成功查询但该时间桶没有调用时，请求、Token、计费产出和调用成本显示真实的 `0`；接口失败显示“无数据”；没有延迟样本时显示“无样本”，不会写成 `0ms`。
- 明确拆分用户 API 计费产出、上游账号调用成本和 API 调用毛利。调用毛利只等于前两者之差，不扣账号采购或资产损失。
- 账号采购投入与封禁减值损失继续进入独立资产账本，不再与 API 调用成本并列成同一种成本。
- 六个经营图表使用 `usage_logs`、Ops 和经济采样的真实值；成功空桶补零，数据源失败和不可观测的延迟保留缺口。

## 技术变更

- 当天快照、账号当日统计和 `usage_logs` 兼容查询使用同一用户设备日历边界。
- 财务趋势的补齐桶保留数值 `0`；来源错误仍保持不可用状态，避免把查询失败解释为零业务。
- 资产总览新增所选窗口 API 计费产出、上游调用成本、调用毛利、账号采购和账号资产损失的独立指标。
- 经营趋势的调用毛利不再减去固定采购费率；采购回本和贡献分析仍保留在独立的单位经济性视图。
- Release 构建前强制校验 `主要更新`、`Windows 原生一键启动` 与当前兼容内核章节，避免核心用户功能或内核身份再次遗漏。

## 升级行为

- `v0.2.22` 至 `v0.2.27` 可通过桌面自动更新直接升级到 `v0.2.28`，也可运行 NSIS 安装包原位升级；本地配置与已保存启动目录保持不变。
- 桌面升级不会改写 Codex、Claude Code、Cursor、OpenCode 或 Grok 的账号配置文件。
- 内核仍使用活动、待激活和上一版三个槽位；候选内核通过身份与能力校验后才会激活。

## 数据与兼容性

- 用户 API 计费产出：`SUM(usage_logs.actual_cost)`，USD。
- 上游账号调用成本：请求价格快照乘账号倍率，USD。
- API 调用毛利：用户 API 计费产出减上游账号调用成本，USD。
- 账号采购与封禁减值：独立 CNY 资产账本，不属于 API 调用成本。
- 正常空桶的 `0` 表示该桶确认没有调用；“无数据/无样本”表示数据源失败或指标不可观测，两者不会互相替代。

## 验证结果

- 回归测试覆盖用户设备当天边界、成功空桶零值、失败来源空态、延迟缺样、API 毛利公式以及采购/减值分账。
- Rust 启动器测试覆盖 ChatGPT Desktop、Codex CLI、Claude Code、Cursor Agent、OpenCode、Grok CLI 与 PowerShell 回退路径。
- Release 校验会阻止版本号、必需章节或一键启动说明缺失的发布。

## 回滚说明

- 桌面更新与内核回滚相互独立；回滚桌面不会自动降级当前已验证内核。
- 新内核首次启动健康检查失败时自动恢复上一版内核。
- 启动器不写客户端账号文件，因此卸载或回滚桌面端不需要恢复 Codex/Claude 等客户端配置。
