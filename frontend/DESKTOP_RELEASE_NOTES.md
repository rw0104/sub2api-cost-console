# Sub2API Cost Console v0.3.12

## 主要更新

- 修复 v0.3.11 检查上游内核时提示“兼容内核清单缺少桌面所需能力: openai.oauth.request_header_probe.v1”的发布通道不一致问题。
- 桌面与稳定内核同步发布，上游基线仍为 v0.2.8，本地扩展升级至 v1.3.4。
- 补回上游同步时遗漏的推理力度倍率计费、模型目录投影、独立 credits 缓存，以及终局账号成本损失和恢复冲销的生产调用。
- 保留 Windows 原生一键启动、原应用身份及既有数据库、配置和插件。

- 桌面：`v0.3.12`
- 上游 Sub2API：`v0.2.8`
- 上游提交：`fd80b08c90b55edcad5b00171b53f08721d30da1`
- 本地扩展：`v1.3.4`

## 技术变更

- 内核同步检查现在比较能力集合，即使上游版本相同，旧清单缺少新桌面所需能力也会触发更新。
- 桌面发布要求同一源码提交的完整后端 CI 成功，并在安装器发布前上传实际内核包、SHA-256 及能力清单，再下载验证。不能通过只修改清单或降低能力校验绕过二进制验证。
- 可配置推理力度倍率进入 token、按次、图片、视频及账号成本计算。新模型匹配恢复独立 fallback、别名隔离和显式零价；保留本地已更新的 GPT-5.6 价格。
- 账号模型选择器基于当前映射投影原始目录；quota credits 和 reset credits 分别缓存并报告各自结果。
- 终局失效通知与恢复冲销接回成本损失服务，生产 Wire 注入同步修复。普通临时失败仍不应产生终局损失。
- 清理历史 lint 债务；安全扫描的可信测试输入和固定哈希路径逐点记录依据，不关闭全局安全检查。

## 升级行为

- v0.3.11 用户可先重新检查内核更新，取得扩展 1.3.4；随后通过桌面更新或本安装器升级至 v0.3.12。手动安装前退出桌面和托盘，沿用原安装目录并保留应用数据。
- 版本变化后插件会按现有升级规则停用一次，配置和包保留；检查后重新启用，Header Probe 1.0.1 无需重装。
- 新计算规则作用于之后的请求，本版本不会重写历史计费记录或批量补写历史成本损失账本。
- 外部独立后端需要更新实际宿主；更新本机桌面不能替代外部服务升级。

## 验证结果

- 发布须通过完整后端 unit/integration 测试及 golangci-lint；另执行桌面 Rust、全部前端、SDK 与内核发布契约检查。
- 新增内核清单契约回归：缺少 Header Probe、身份/通道不符、下载地址异常及包大小/SHA-256 不符均被拒绝。
- 旧的渠道/WS 路由测试使用固定价格样本，避免最新模型价格变化引起不相关失败，保留原金额断言。
- 当前 v2 原生 WebSocket Hook 覆盖、通用 Provider Adapter、事件消费及 Worker 的限制仍存在，本版本不宣称补齐所有 v2 扩展功能。

## 回滚说明

- 升级前可保留数据库和应用配置备份；本次不新增数据库迁移。
- 回退旧桌面/内核可能重新出现功能接线缺失、健康探测取消或旧能力清单的问题。
- Tauri updater 的 `.sig` 用于自动更新验签，不代表 Windows Authenticode 发行者签名。
