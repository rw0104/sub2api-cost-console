# Sub2API Cost Console v0.4.6

## 主要更新

### 跟进 Codex 客户端 0.166.0

Codex CLI `0.166.0` 稳定版于 2026-10-29 发布。逐文件比对 `rust-v0.165.0` 与 `rust-v0.166.0` 源码，请求头、`ResponsesApiRequest` 字段、`/models?client_version=` 与 ETag 逻辑、内置模型目录都没有变化，网关不需要改协议。本版只跟进以下行为变化：

- **识别新错误码。** Codex 0.166 新增 `policy_capacity_unavailable`（受策略限制的容量暂不可用，openai/codex#57452）。网关在 HTTP、流内和 WebSocket 三条路径上把它与 `server_is_overloaded`/`slow_down` 同样当作请求级容量降载处理：
  - 先在同一账号按 Retry-After 重试（最长 8 秒）；
  - 不把账号摘出调度；
  - 流式和 WebSocket 路径转发给客户端前改写为可重试的 `server_error`，并保留原错误消息；
  - HTTP 路径重试用尽后，返回通用的过载提示。
- **统一 provider ID。** Codex 0.166 起，会话只能用创建时记录的 provider ID 恢复（openai/codex#57840）。「API 接入」页复制的 Codex 配置改用与桌面「启动 Codex CLI」相同的 provider ID `sub2api`，原来是 `Sub2APILocal`。两种入口创建的会话现在可以互相 resume。
- **更新版本兜底。** 内置 Codex 客户端版本兜底改为 `0.166.0`，桌面生成的模型目录地址同步使用 `client_version=0.166.0`。管理员覆写和自动同步的版本仍优先。

### 计费修正

gpt-6.1-sol 的 Ultrafast 改按官方价计费。OpenAI 自 2026-10-08 起提供 gpt-6.1-sol Ultrafast，官方价为标准价的 6 倍：

| | 输入 | 缓存读取 | 30 分钟缓存写入 | 输出 |
| --- | --- | --- | --- | --- |
| 短上下文 | 12 | 0.60 | 15 | 60 |
| 长上下文 | 24 | 1.20 | 30 | 90 |

此前网关按通用的 2 倍计算，只计到应收的三分之一。Fast（priority）档仍为 2 倍；gpt-6.1-terra 等没有官方 Ultrafast 价的模型不变。

### 成本算法 1.7.0（预测规则 1.2.0）

- **影子账号不重复计费。** Spark 影子账号不持凭据，借用母账号的订阅。没有自定义成本档案时，影子账号的默认采购价为 0，同一份订阅不再计两次；为影子账号显式填写的固定成本仍然生效。
- **成本档案前后端口径一致。** 后端按前端相同的规则归一化计费周期，`One-Time`、` Monthly ` 这类写法在两端结果一致，不再出现前端照算、后端判为无效的情况。
- **单条坏档案不再拖垮快照。** 已删除账号中任何一条格式异常的成本档案，此前都会让整个「渠道号池」经济快照报错。现在这类档案只计入“成本档案不完整”，并把数据标为部分可用；已删除账号的档案也按创建时间限制起算点，与现存账号一致。
- **已删除账号按已付周期计入。** 本月开始计费、之后已删除的按日、按周或按小时付费账号，按删除前（已确认终局的按终局前）已开始的周期数计入本月采购，此前只计 1 个周期。
  - 例如按日付费保留 5.5 天，计 6 天。
  - 月付账号在首个 730 小时周期内删除，仍计 1 个周期；一次性采购不变。
  - 所选时段的新增采购同样在删除时刻停止累计。
- **汇率回退标为部分可用。** 联网和缓存都取不到汇率、使用 7.2 回退值时，经济数据标为部分可用，不再显示为完整。
- **号池预测更保守：**
  - 相邻采样间隔超过 30 分钟的区间不计入速率。这类间隔来自内核停机，或分渠道页面未打开时的采样空档；不计入可以避免把停机时段当作零产出拉低速率。
  - 预测至少使用最近 1 小时的采样，所以最近 1、5、15 分钟等短时段也能给出预测。图表和样本数仍只统计所选时段。
  - 稳定采样不足 15 分钟时，产出速率和综合成本卡片显示实测速率，剩余产出和回本时长暂不显示。
  - 平均健康账号少于 1 个时不做产能放大，当前没有健康账号时预测为 0，产能调整最多 2 倍。

- Windows 原生一键启动、插件协议、SDK 和六项必需能力与上一版保持兼容。

## 技术变更

- `isOpenAICapacityShedErrorCode` 统一请求级容量降载码集合，四处调用方共用：HTTP 瞬时错误判定、流内 failed 事件判定、客户端错误码改写、WS 状态映射。新增码只扩大该集合，其他错误码的分类不变。
- `codexCLIVersion` 与前端 `DEFAULT_CODEX_CLIENT_VERSION` 改为 `0.166.0`。
- 计费：`applyModelSpecificPricingPolicyEx` 对 gpt-6.1-sol 设置 `UltrafastMultiplier = 6`，与 gpt-6-astra 一致。价格目录文件未改动。
- 成本：
  - `resolveAccountCostProfileSnapshot` 按 `[\s-]+ → _` 归一化计费周期，影子账号（`ParentAccountID != nil`）的默认价为 0。
  - 新增 `ParseAccountProcurementProfile`，仓储层用它解析已删除账号的成本档案，同时读取 `deleted_at` 与 `created_at`；解析失败的行标记为 `Invalid`，不再返回错误。
- 预测 1.2.0：
  - `AccountEconomicsProjection` 新增 `gap_intervals` 字段。
  - 低置信度时 `capacity_adjusted_*` 为 `null`，当前没有健康账号时 `capacity_adjustment` 为 `0`；直接读取经济快照接口的脚本或插件需要处理这两种值。
  - 预测采样窗口为 max(所选时段, 1 小时)。
  - 前端只把剩余产出等预测类指标标为部分可用，事实类采购与损失卡片不受影响。
- 前端 `ALGORITHM_VERSION` 与后端 `CostAlgorithmVersion` 新增一致性测试，共享对齐样例新增影子账号和计费周期拼写共 4 例。
- 没有数据库迁移。

## 升级行为

- 可在“版本与更新”中升级，也可以退出程序后使用安装器原位升级。
- **影子账号成本下降。** 有 Spark 影子账号且未单独配置成本的号池，采购累计、预计月采购和每 1 USD 产出采购成本会下降，因为不再重复计入影子账号的母账号套餐价。
- **Ultrafast 计费上升。** 使用 gpt-6.1-sol Ultrafast 的请求，从升级后起按 6 倍标准价计费。历史用量记录保留请求时的金额，不会重算。
- **预测更严格。** 号池预测在最近 1 小时内稳定采样满 15 分钟后才显示；跨越内核停机的区间不再计入，所以重启后的速率可能高于旧版本显示的值。分渠道页面只在打开期间采样，关闭期间的产出不参与该渠道的速率估计。
- **重新复制配置的影响。** 用旧的 `Sub2APILocal` 配置创建的 Codex 会话，在重新复制配置并切换到 `sub2api` 后，Codex 0.166 无法再恢复这些会话，0.167 起会以只读方式打开。需要继续这些会话时，可暂时保留旧的 provider 段。
- **版本变化后首次启动。** 桌面、兼容内核或扩展版本变化后的首次启动，会停用旧插件一次，保留配置、已签名原包、发布者信任和路由作用域；确认兼容后重新启用。
- **发布顺序。** 兼容内核先于桌面安装器发布，校验版本、上游提交、扩展版本、能力清单和归档 SHA-256，并在发布后下载回读。

## 验证结果

- 新增回归测试在修复前失败、修复后通过，覆盖以下 4 部分：
  - `policy_capacity_unavailable` 在 HTTP、流内、WS 与客户端改写路径的处理；
  - gpt-6.1-sol Ultrafast 的短/长上下文四个价格分项；
  - provider ID 与桌面启动器一致；
  - 成本算法 1.7.0 的计费周期归一化、影子账号、异常档案、已删除周期采购、汇率回退、采样间隔、低置信度和产能调整上限。
- 最终发布门禁要求同一源码 SHA 通过以下检查，结果以对应 GitHub Actions 执行记录为准：
  - 完整后端 unit、integration、golangci-lint；
  - 插件契约、生命周期、路由范围、V1/V2 与 race；
  - 完整前端测试与 lint；
  - Rust 桌面测试和生产构建。
- **Codex 0.166 跟进未经真实账号核对。** 依据是 Codex `rust-v0.166.0` 源码与 PR 说明，尚未用真实账号抓取 0.166 请求，也没有在生产环境观察到 `policy_capacity_unavailable`。
- **gpt-5.6-sol 促销价未采用。** OpenAI 页面标注 gpt-5.6-sol 促销价 4 / 0.40 / 20，至少持续到 2026-11-21。价格目录仍为 5 / 0.50 / 30；需要按促销价计费的运营者，请用分组或渠道自定义价格覆盖。
- **12 小时缓存写入未区分。** 12 小时缓存写入价是 30 分钟写入价的 2 倍，本版仍按 30 分钟价计。Codex 请求不指定缓存 TTL，主要影响主动请求 12 小时缓存的 SDK 客户端。
- 安装器、Tauri 更新签名、更新清单、稳定内核和开发包须在发布后重新下载，核对版本、能力及 SHA-256。

## 回滚说明

- 本轮可回退到桌面 v0.4.5 及匹配的内核 `v0.2.19` / 扩展 `1.3.24`，两者上游基线相同，且本版没有数据库迁移。回退后影子账号恢复按母账号套餐计费，gpt-6.1-sol Ultrafast 恢复按 2 倍计费，号池预测恢复 1.1.0 规则。
- 兼容内核稳定通道不允许降级发布，也不允许同名包更换内容。出现问题时向前修复并递增扩展版本；客户端可使用本地回滚槽位回到上一个内核。
- Tauri updater 的 `.sig` 用于自动更新验签，不代表 Windows Authenticode 发行者签名。
