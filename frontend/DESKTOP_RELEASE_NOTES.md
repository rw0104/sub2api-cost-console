# Sub2API Cost Console v0.4.8

## 主要更新

- 合入正式上游 v0.2.21，保留宿主插件、成本与桌面功能。同步 Codex 页面上下文、密封工具调用、元数据事件重试、OAuth WS 搜索激活重连及后续回合防重放修复。
- Codex 稳定兼容基线更新为 0.167.2；另对本机桌面随附 0.167.0-alpha.4.1 做隔离环回请求捕获。补齐根回合、父回合、线程和上下文窗口身份引用。
- 旧客户端直接发送 ultra 时，按模型目录的多代理推理档位归一化（当前 Sol/Terra/Astra 为 xhigh，旧模型按支持档位回退），再执行分组映射、上限或拒绝规则；保留 Ultra 多代理模式和元数据。
- 同步 OpenAI 缓存写入 30m/12h 明细、计费和展示，补齐 WS 路径，并验证历史 1h 渠道价与 priority、长上下文组合。
- 同步请求体内存自适应预算、刷新令牌原子轮换、账号加载失败释放名额、列表刷新稳定性、六位小数充值倍率及设置页底部保存操作。
- 发布要求同一源码 SHA 的全部独立后端 CI 最新运行成功；未提交的临时合并内核不能发布。保留插件 readiness、drain、作用域、升级、回滚及停用回归。
- 修复 WebSocket 同一回合重复终局事件的重复结算；保留事件透传，新请求仍可形成独立结算。
- Windows 原生一键启动沿用客户端探测、正式应用身份、数据目录和端口。桌面与稳定内核同步发布。
- 构建工具链统一升级至 Go 1.27.4，修复 GO-2026-6859 / CVE-2026-97054：HTTP/1 请求体超限时，MaxBytesReader 与并发响应头写入可能触发进程崩溃。后端、CI 与 Docker 构建版本同步更新。

## 技术变更

保留宿主推理倍率和渠道字段，合入缓存 TTL 存储与查询，不修改已应用迁移的校验值。Terra 长上下文计费沿用账户配置，保留 Sol 订阅豁免和 Ultrafast 规则。Ultra 兼容转换只处理推理参数，不改诊断元数据或原生 Anthropic 语义。无客户端回合标识时保留随机回退。

发布前分别记录上游基线与宿主源码 SHA；内置内核、core-stable、能力、签名、哈希及 SDK 必须同源。第三方插件继续在独立仓库维护。

## 升级行为

从“版本与更新”升级，或退出后运行安装器原位升级；沿用数据库、配置和端口 18765。桌面/内核/扩展身份变化后的首次启动，按已有规则停用旧插件一次，保留配置、签名原包、发布者信任及作用域；确认兼容后重新启用。

Ultra 仍可选，请求受分组策略约束。请求体预算不是进程总内存上限，显式配置与零值行为以配置说明为准。图片原生接口及实际输出格式见 docs/OPENAI_IMAGES_CODEX.md。

## 验证结果

发布须通过最终同一源码 SHA 的完整后端 unit/integration/lint、插件契约/生命周期/作用域/V1/V2/race、前端、Rust 和打包检查。执行状态以本版本 GitHub Actions 与验收报告为准。

协议及插件回归使用合成账号和隔离测试数据，不代表所有真实套餐及第三方插件均已验证。发布后重新下载安装器、签名、稳定内核和 SDK，核对版本、能力、哈希、签名与内置/稳定内核一致性。

## 回滚说明

可使用已有回滚槽位退回 v0.4.7 对应 core 0.2.20 / extension 1.3.26；保留新增字段和索引，不手工删表或改历史迁移。旧版不具备本轮修复。稳定通道禁止低版本覆盖及同名 ZIP 替换字节；重打包递增扩展版本。Tauri .sig 用于自动更新验签，不等于 Windows Authenticode 签名。
