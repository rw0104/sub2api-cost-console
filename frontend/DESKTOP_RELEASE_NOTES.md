# Sub2API Cost Console v0.4.9

## 主要更新

- 整合 Sub2API v0.2.23，适配 Codex 0.170.0。HTTP 和 WebSocket 继续使用 `/v1/responses`。WebSocket 握手公布网关实际执行的消息大小上限，客户端可以提前为大请求选择 HTTP。
- 普通 HTTP、透传和 WebSocket 均可转发客户端提供的子代理角色。连接池按角色区分握手，在账号切换时保留线程与请求 ID 的对应关系。
- OpenAI 推荐模型新增 GPT-6.2 Sol 和 GPT-6.2 Astra。编辑账号时，可获取该账号的官方模型目录，用面板的补齐按钮将缺少的模型加入草稿，再保存账号。已有精确映射、通配符规则和自定义别名仍然生效。
- 渠道支持 Ultra Fast 倍率，分组可为支持的模型指定 Ultra Fast。账号用量分别返回用户实际扣款和账号成本，保留首次及末次使用时间。HTTP 与 WebSocket 均支持 30m/12h 缓存时长选项。
- 插件宿主支持 V1/V2、作用域路由、请求头观察、保护传输、发布者信任、热升级和回滚。拒绝和超时请求的扣费行为，以及并发请求的逐次结算，均有端到端回归。

## 技术变更

WebSocket 将配置的消息读限同时用于握手响应和入站帧校验。网关保留客户端请求 ID 与线程 ID 之间的关系。插件宿主沿用六项必需能力，使用当前 SDK 的插件可继续使用原有 V1/V2 接口。

## 升级行为

从「版本与更新」升级，或退出应用后原位运行安装器。Windows 原生一键启动沿用已有数据库、配置、应用身份和端口 18765。首次启动切换内核身份时，已安装的插件会按既有规则停用一次。确认兼容性后可重新启用，原配置、签名包、发布者信任和作用域均保留。

## 验证结果

账号编辑已在真实浏览器、临时数据库和受控模型目录上验证过获取、补齐、保存与重开。插件生产 E2E 覆盖拒绝与超时零扣费、热升级、回滚、停用及 24 个请求在 8 并发下逐次结算。正式资产的签名、SHA-256 及内置和稳定内核的一致性见本版发布附件。

## 回滚说明

需要回退时，可从已有回滚槽位切回 v0.4.8 配套内核 0.2.21 / 扩展 1.3.27。数据库迁移保留。桌面更新签名、安装包 SHA-256、插件 SDK 及其校验文件见本版发布附件。
