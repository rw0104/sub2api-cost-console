# Sub2API Cost Console v0.2.32

## 主要更新

### 兼容内核升级到 v0.2.2

- 将兼容内核从上游 `v0.2.1` 升级到 `v0.2.2`，新增分组模型白名单，统一约束模型列表与网关请求准入；推理强度映射支持设置为“拒绝”。
- 简单模式支持基础账号分组、能力白名单和分组边界管理；账号到期新增月/年快捷选项，订阅页可跳转查看用户用量。
- 修复 DeepSeek 高峰时段账号成本少计、GLM-5.3/Flash 兜底价格匹配和 Gemini 3.7/3.8 Flash 思考层级定价；模型广场适配缓存价格和分时倍率。
- 修复 model-not-found 故障切换、Codex 清单路由和调度、混合账号默认模型列表，以及 WebSocket 配额恢复、HTTP 桥接状态隔离和透传会话槽回收。
- 修复 Claude Code 版本伪装与思考 block binding、Codex allowed_tools 约束、Astra Ultra 元数据和推理模式保留、GPT-6 Astra 系统指令选择。
- 修复 Grok 媒体账号计费状态处理、Fable 额度错误作用范围、Antigravity toolConfig、Responses API 独立输入和缓存 JSON 转义。
- 数据库备份与迁移锁串行化；兑换码失败限流使用固定 10 分钟窗口，并与支付履约限流隔离。

### 成本控制台与 Windows 原生一键启动

- 保留成本损失账本、经济采样和成本真实性面板；刷新失败保留最近成功快照，缺少账号成本数据时标记估算。
- 继续分别展示用户计费产出、上游账号成本、采购投入和封禁损失，模型核对保留请求、上游发送与响应声明三个维度。
- Windows 原生一键启动继续支持 ChatGPT Desktop、Codex CLI、Claude Code、Cursor Agent、OpenCode 和 Grok CLI；保留本地客户端路径与工作目录。

## 升级行为

- 旧桌面通过签名自动更新或 Windows x64 NSIS 安装包升级至 `v0.2.32`；新安装包内置 `v0.2.2` 兼容内核。
- **模型白名单行为变化：既有模型列表配置在迁移后会成为请求准入白名单。启用白名单的分组会拒绝名单外模型，升级前应核对现有分组配置。**
- 独立内核通过 `core-stable` 发布；客户端验证版本、上游提交、必需能力与 SHA-256 后进入待激活槽位。
- 保留本地应用配置、已保存工作目录和现有成本数据。

## 验证结果

- 发布门禁覆盖 Go 单元与数据库集成测试、静态检查、前端全量测试、ESLint 和生产构建。
- Windows 内核工作流覆盖 Go 默认测试和 Rust 内核身份、激活、健康检查失败回滚及启动器测试。
- 安装包由 GitHub Actions 构建，生成 Tauri updater 签名、自动更新清单与 SHA-256 校验文件。
- 发布后重新下载内核及安装器，核对内核身份、归档哈希、安装包更新签名和公开自动更新入口；最终结果记录在仓库发布报告。

## 回滚说明

- 新内核首次启动健康检查失败时自动恢复上一版内核，桌面回滚不会自动降级已验证内核。
- 本版有数据库列重命名迁移；内核二进制回滚不会撤销数据库迁移。需要退回旧内核时，应使用升级前数据库备份配合恢复。
- 启动器继续只向新启动进程注入连接配置，不改写客户端账号文件。
