# Sub2API Cost Console v0.2.31

## 主要更新

### 兼容内核升级到 v0.2.1

- 将内核从上游 `v0.2.0` 升级到 `v0.2.1`，集成 GPT-6 Astra 模型和能力同步、Codex Ultrafast 服务层级及固定账号模型清单。
- 新增 OpenAI 消息提示缓存、Claude 对外 CLI 版本配置、Anthropic reasoning effort 定价控制和定价文件热加载；reasoning 映射支持以 `none` 为来源。
- 用量记录保存上游请求标识，支持按账号配置响应头名称；图片生成支持下载上游图片 URL 并回填 `b64_json`，同时校验目标地址和内容类型。
- 账号列表支持紧凑响应；网关调度逐账号检查渠道模型限制；WebSocket 重放共享不可变正文，降低长会话内存开销。
- 修复 Astra 能力和续聊状态持久化、模型列表获取失败后的能力保留、Gemini 自定义原生模型列表、工具发现回退和 OpenCode 会话转发。
- 修复 heartbeat 启动、历史任务委派续聊、不可用 continuation 恢复、API Key reasoning effort 透传、转发失败后的会话槽释放及上游错误归因。
- 保留成本损失账本、经济采样、成本真实性面板及 Windows 原生客户端启动能力。

### 成本数据真实性与面板

- 刷新或单个来源失败时保留最近成功快照，并标明旧数据或不可用状态。
- 分别展示用户 API 计费产出、上游账号成本、采购投入和封禁损失；缺少账号成本快照时明确标记估算。
- 总览保留一张财务事实趋势图，诊断统计按需展开；模型核对区分请求模型、实际发往上游模型和响应声明模型。

### Windows 原生一键启动

- 分别探测和启动 ChatGPT Desktop、Codex CLI、Claude Code、Cursor Agent、OpenCode 和 Grok CLI。
- 工作目录和有效客户端路径保存在本机；CLI 优先使用 PowerShell 7，缺失时回退 Windows PowerShell 5.1。
- Base URL、API Key 等只注入新进程；不改写客户端账号文件。ChatGPT Desktop 负责启动官方应用。

## 技术变更

- 按已集成的 `v0.2.0` 源码树合并官方 `v0.2.1` 增量，并固定上游提交；版本信息同时写入 Go sidecar 和 Tauri 桌面元数据。
- 同步此前已发布的源码和内核同步修复到主分支，使自动更新使用实际发布基线。
- 上游数据库迁移包含请求标识字段及索引、Codex 模型清单配置和最高推理强度计费倍率，由内核启动迁移流程执行。
- 保留本地成本扩展与价格回退规则；用户 API 调用毛利继续只等于计费产出减账号调用成本，采购和减值进入独立资产账本。

## 升级行为

- 旧版桌面可通过签名自动更新或 NSIS 安装包升级至 `v0.2.31`，保留本地配置和已保存目录。
- 兼容内核通过 `core-stable` 通道发布，下载后验证版本、提交、能力和 SHA-256，再进入待激活槽位。
- 新安装器内置 `v0.2.1` 兼容内核；桌面更新与独立内核更新均使用相同上游身份。

## 验证结果

- 发布前运行 Go 单元及默认测试、前端全量测试、ESLint、Web 和桌面前端生产构建。
- 桌面 Rust 测试覆盖内核身份、激活、健康检查失败回滚和客户端启动器。
- 构建后核对 sidecar `--version`、成本扩展能力及内核归档 SHA-256。
- GitHub Actions 生成 Windows NSIS 安装包、Tauri updater 签名、更新清单和校验文件。

## 回滚说明

- 新内核首次启动健康检查失败时自动恢复上一版内核；桌面回滚不会自动降级已验证内核。
- 本版包含数据库迁移；内核二进制回滚不代表数据库迁移会撤销。
- 启动器不改写客户端账号文件，桌面卸载或回滚不需要恢复 Codex、Claude 等客户端配置。
